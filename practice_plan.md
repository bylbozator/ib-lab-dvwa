# План практики (1 неделя) — чтобы резюме не было «пустым»

Цель: за неделю получить реальный практический результат, который ляжет в блок «Проекты» резюме и уверенно обсуждаться на собеседовании.

## Дни 1–2: Окружение и первые инструменты
1. Установить VirtualBox (или использовать WSL2/Docker) — поднять лабораторию.
2. Развернуть DVWA в Docker:
   ```
   docker run -d -p 8080:80 vulnerables/web-dvwa
   ```
   Открыть http://localhost:8080, войти (admin/password), перейти на вкладку Setup и нажать Create / Reset Database.
3. Изучить интерфейс: разделы BruteForce, SQL Injection, XSS, Command Injection.

## Дни 3–4: Проход по OWASP Top 10 на DVWA
Для каждой уязвимости выполнить: эксплуатация → записать шаги → оценить риск → рекомендация.
Минимальный набор (уровень Low → Medium):
- SQL Injection (обход авторизации, UNION-запросы)
- XSS отражённый и хранимый
- Command Injection (проверка ввода, reverse shell)
- File Upload (загрузка небезопасного файла)
- Burte Force (взлом пароля) + Session Hijacking для понимания логики

Инструменты: Burp Suite Community (перехват, Repeater), запись с Wireshark.

## День 5: Web Security Academy (PortSwigger) — обязательно
Бесплатная платформа от создателей Burp Suite, прямо на сайте портсвиггер.
- Пройти 2–3 лаборатории: SQL injection (single quote), Authentication (username enumeration), Business logic.
Результат — официальные completion-проценты, которые можно указать в резюме и рассказывать на собеседовании.

## День 6: Практическая разведка
- nmap против своей лаборатории: `nmap -sV 127.0.0.1 -p 1-1000`
- Подбор каталогов (dirsearch / gobuster) против DVWA
- Осмысление разницы «сканер нашёл» vs «аналитик подтвердил» — это язык отчёта пентестера.

## День 7: Оформление результатов
1. Оформить отчёт по одной уязвимости как в реальном пентесте: CVSS-оценка (калькулятор first.org/cvss), описание, доказательство (скрин/лог), рекомендация.
2. Обновить в резюме: убрать пометку «базовый уровень» у Burp Suite, указать количество пройденных лабораторий Web Security Academy.
3. Откликнуться снова (см. cover_letter.md), добавив в сопроводительное конкретику: «На прошлой неделе в лаборатории DVWA эксплуатировала SQL-инъекцию типа UNION и подготовила отчёт с оценкой риска».

## Полезные ресурсы (бесплатные)
- PortSwigger Web Security Academy — labs.portswigger.net (обязательно)
- Hack The Box Academy (стартовые модули бесплатны)
- TryHackMe — пути Beginner Path (бесплатные комнаты)
- DVWA, OWASP Juice Shop (в Docker: `docker run -d -p 3000:3000 bkimminich/juice-shop`)
- Калькулятор CVSS: https://first.org/cvss/calculator/4.0

## Чего НЕ делать
- Не указывать в резюме то, чего реально не делали.
- Не пытаться «хакать» чужие системы — только собственные лаборатории и официальные платформы.
- Не торопиться: для пары эта вакансия, скорее всего, не единственная — параллельно откликаться на аналогичные (напр., «Специалист по информационной безопасности», «Аналитик ИБ», «Тестировщик на проникновение (Junior)»).
